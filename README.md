# Agent Atlas

Проект Agent Atlas — моя личная система изучения ИИ-разработки.

## Цель

Agent Atlas помогает мне системно разбираться в разработке с использованием ИИ, а не собирать знания случайными обрывками.
Я превращаю разрозненные материалы в структурированную базу знаний и понятный план обучения.
Каждая изученная тема должна заканчиваться практикой и измеримым результатом: кодом, заметкой или работающим проектом.

## Цикл работы

```
Источники → Отбор → Знания → План → Практика → Результат
```

1. **Источники** — собираю статьи, документацию, курсы, видео и репозитории по ИИ-разработке.
2. **Отбор** — оставляю только то, что актуально, качественно и полезно для моих целей.
3. **Знания** — конспектирую главное своими словами и связываю с уже изученным.
4. **План** — определяю, что изучать дальше и в каком порядке.
5. **Практика** — закрепляю знания на упражнениях и небольших проектах.
6. **Результат** — фиксирую итог: готовый код, выводы и новые вопросы, которые становятся источниками для следующего круга.
